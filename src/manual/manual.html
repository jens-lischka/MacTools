StudioTools

A Creative Studio Solution — enhanced features for macOS and web

StudioTools is a PowerPoint add-in that speeds up slide work — alignment, sizing, text, shapes, tables and more. Every tool lives in one task pane, grouped by category. It runs identically in PowerPoint on the web, on macOS and on Windows.

How it works

Open the pane from the StudioTools button on the Home tab. Most tools act on the shapes you have selected on the current slide — select first, then click a tool. A status bar at the top of the pane reports the result of each action.

Some tools need a newer PowerPoint API than the user's Office build provides. Those tools disable themselves automatically and explain why — the rest keep working.

Alignment & Distribution

Choose what to align relative to — the selection bounds, the first or last selected shape, or the slide — then align or distribute.

Align Left / Center / RightAligns selected shapes horizontally to the chosen target.
Align Top / Middle / BottomAligns selected shapes vertically to the chosen target.
Distribute Horizontally / VerticallySpaces 3+ shapes so the gaps between them are equal.

Size & Position

Match Width / Height / BothResizes selected shapes to the first or last selected reference shape.
ScaleScales selected shapes by a percentage, about their centre.
Stretch Left / Right / Top / BottomExtends one edge of each shape out to the selection or slide edge.
Fill GapsExtends shapes so the gaps between neighbours are closed.
Unify SizeResizes every selected shape to match the largest one.
Straighten LinesFlattens selected line shapes to be perfectly horizontal or vertical.

Select Same

Select one reference shape, then pick a property — every shape on the slide matching it is selected.

Fill / Outline Colour, Outline WeightMatches shapes by fill or outline styling.
Font, Shape Type, SizeMatches shapes by font name, type or dimensions.
Position (matching edge)Matches shapes that share a top, left, right or bottom edge.
Hide Selected / Show AllHides the selected shapes, or restores every shape on the slide. (Needs API 1.10.)

Text & Paragraph

Autofit, Word WrapToggles shape-to-fit-text autosize and word wrap.
Text-box MarginsApplies margin presets or a custom value to the text box.
Paragraph AlignmentLeft, centre, right or justify.
Clear Line Breaks / Clear TextJoins multi-line text to one line, or empties the shapes.
Bullets, Text StyleShows/hides bullets; matches bullet levels to the slide master's body placeholder; applies Heading / Subheading / Body presets.
Merge / Split TextCombines text of several shapes, or splits lines into separate boxes.
Special CharactersInserts a symbol at the text cursor.

Swap, Pick up & Apply

Swap Position / Size / Fill & OutlineSwaps a property between exactly two selected shapes.
Pick Up / ApplyStores one shape's size & position, then applies it to the selected shapes. Remembered across documents.
Apply to Matching ObjectsApplies the picked-up size & position to every shape in the presentation that matches the selected reference shape by type and size.

Tables

Table tools need PowerPoint API 1.8. On older clients they disable themselves.

Insert TableAdds a table with the chosen rows and columns.
Add / Delete Row & ColumnAppends or removes the last row or column of the selected table.
Convert Table to TextCopies the table's contents into a tab-separated text box.

Slides & Presentation

Export Slide TitlesLists every slide title for copying.
Insert Table of ContentsBuilds a numbered contents list from the slide titles.
Add Sticky NoteAdds a coloured note stamped with your initials and the date.

Special Shapes

Title, Conclusion, Footnote, Ghost, LabelInserts a pre-formatted text box of the chosen kind on the slide.

Utilities

Replace FontsSwaps one font for another across the whole presentation (blank "from" replaces all fonts).
CAGRComputes a compound annual growth rate and inserts it as a text box.
File SizeReports the size of the current presentation.

Settings

Slide SizeSets the slide dimensions used by the align/stretch-to-slide tools. Stored with the presentation.
Default InitialsRemembers your initials for sticky notes.
Reset Defaults / Online HelpRestores default settings, or opens this manual.
Some legacy tools cannot be rebuilt yet because the PowerPoint JavaScript API does not expose the needed capability — for example slide guides, sections, slide-image export and picture effects. These are listed inside the task pane with the reason, and will be added if the API gains support.
